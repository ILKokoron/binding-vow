# Frontend

Single-page app, four screens in flow order:

1. Create vow: raw to-do in, notary-proposed proof terms out, user sets
   stake, deadline, forfeit destination, approves terms, seals the vow.
2. My vow: the NFT, sealed terms, countdown to deadline, stake locked.
3. Submit proof: links, file upload (hash computed in browser), video
   link, code word display for photo or video proof.
4. Verdict: swarm reports, vote result, and the one action that remains:
   burn to redeem (success) or the execution record (failure).

Wallet: NEAR testnet wallet connect. All amounts testnet.
